# skill 管理器 0.1.0

首个 Windows 桌面版发布。

## 亮点

- 扫描并展示 Codex 已安装的 skill。
- 自动生成中文 skill 简介。
- 记录 skill 新增、修改和缺失状态。
- 支持手动编辑简介。
- 提供 Windows 桌面窗口、托盘菜单和开机自启动开关。
- 后台服务无终端窗口启动，打开软件时不会弹出黑色控制台标签页。

## 下载

请在 GitHub Release 中下载：

```text
skill 管理器_0.1.0_x64-setup.exe
```

## 注意

当前安装包未代码签名，Windows 可能会显示安全提醒。确认来源可信后选择“更多信息”并继续运行。
